Operator site rescue (first business)

This is the most launchable business lane. It has the shortest path to revenue, requires no inventory, and builds relationships that feed every other lane.

What it is

Simple, fast website and WhatsApp funnel builds for small tourism operators in El Salvador who currently have no English-language web presence or booking flow.

Service tiers

Tier 1: Quick rescue ($150-300)

  • Single-page landing site (hosted on GitHub Pages or similar, zero cost)
  • Hero photo + what you get + price + WhatsApp CTA
  • Mobile-first, loads in under 2 seconds
  • Bilingual (Spanish + English)
  • Delivery: 2-3 days

Tier 2: Full funnel ($500)

  • Everything in Tier 1 plus:
  • WhatsApp Business setup with quick replies and catalog
  • 3-5 bilingual response templates
  • Google Business Profile setup or optimization
  • Basic photo editing and story copywriting
  • Delivery: 5-7 days

Tier 3: Monthly management ($50-100/mo)

  • Respond to English-language leads via WhatsApp
  • Post seasonal updates and photo content
  • Monthly performance snapshot (messages received, bookings)
  • Escalate complex requests to operator

Why agents make this scalable

  • Landing page generation: agent reads operator photos + descriptions, drafts HTML
  • Copy translation: agent produces bilingual copy from Spanish input
  • Template creation: agent generates WhatsApp quick-reply packs
  • Performance tracking: agent monitors WhatsApp response times
  • Content refresh: agent drafts seasonal updates from market research

First 5 targets

  1. Victor (Los Cobanos) — whale watching + reef snorkeling. Existing relationship.
  2. Finca El Carmen (Ataco) — heritage coffee tours. Strong story, weak web presence.
  3. Surf instructor at El Zonte — Bitcoin Beach audience, English-speaking tourists.
  4. Hot springs operator near Ataco — Termales de Santa Teresa or similar.
  5. Boutique hostel in Juayua — birding and highland stays.

Revenue model

  • Year 1 target: 10-15 operator clients
  • Blended revenue: ~$400 average setup + $75/mo management
  • Year 1 projection: $4,000-6,000 setup + $6,000-9,000 recurring = $10,000-15,000
  • Costs near zero (agent labor, free hosting, no inventory)
  • Each client becomes a relationship that feeds other lanes (tours, content, partnerships)

Launch checklist

  • [ ] Build template site generator (agent-assisted HTML from operator input)
  • [ ] Create 3 example sites as portfolio/demo
  • [ ] Pitch Victor on pilot (free Tier 1 as proof of concept)
  • [ ] Document the process for replication
  • [ ] Set up a simple CRM (even a spreadsheet) to track operator pipeline
  • [ ] Write a 1-page pitch deck in Spanish for in-person operator meetings

Success metrics

  • Time from first contact to live site: under 48 hours
  • Operator satisfaction: "this is actually getting me bookings"
  • Repeat engagement: operator wants Tier 2 or Tier 3
  • Referral: operator introduces Shane to another operator

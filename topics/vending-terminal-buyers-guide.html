Vending Terminal Buyers Guide — Lightning QR Feasibility Matrix

Research confidence: mixed. Hardware specs are verified from vendor docs. Bitcoin/Lightning integration is partially confirmed — noted per row.

The core problem: most commercial vending terminals were built for Visa/MC/NFC. Lightning requires dynamic QR code generation tied to a live invoice. That is a software integration problem, not a screen problem — but the screen still needs to be color and large enough to scan.

This page answers: which terminals can physically display a Lightning QR, which have an API path to route payments through a crypto gateway, and what the realistic integration complexity is.

Why Lightning QR is different from card payments

Standard card terminal:

  • Customer taps card → terminal talks to processor → processor approves → vend

Lightning terminal:

  • Customer selects product → terminal requests invoice from Lightning node/gateway → gateway returns a QR string → terminal renders QR on color screen → customer scans with phone → Lightning payment confirmed (< 2 seconds) → gateway webhooks the terminal → terminal triggers MDB vend command

The difference: the terminal must be able to request and render a dynamic QR on demand, not just read a static payment token. This rules out older black-and-white or button-only readers.

| Terminal | Screen | QR capable | API path | Crypto gateway path | Confidence | Source | |---|---|---|---|---|---|---| | Nayax VPOS Touch | 2.4" color touchscreen | Yes — native QR support documented | Cortina API (third-party gateway hook) | BitPay, OpenNode, GoCrypto via Cortina | Medium — API confirmed, crypto path theoretical | Nayax developer hub | | Cantaloupe Engage Pulse | Edge-to-edge color touchscreen | Yes — designed for dynamic QR | Cantaloupe SDK / Seed API | Bakkt partnership (bitcoin via Bakkt app); Lightning path unconfirmed | Low-Medium — Bakkt bitcoin path confirmed in 2021, Lightning unconfirmed | Cantaloupe store | | Raspberry Pi + 7" touchscreen | 7" color, full control | Yes — full custom | Any (BTCPay, LNbits, OpenNode) | BTCPay Server — fully verified | High — proven in DIY builds | Hackster.io Ricardo Reis build | | ESP32 + TFT display | Small TFT, low cost | Yes — custom firmware | LNbits LNURL API | LNbits — verified | High — open source build exists | GitHub mdb-esp32-cashless | | CPI / Crane readers | Varies by model | Depends on model | CPI SDK (enterprise) | No native crypto; custom middleware possible | Low — no public Lightning doc found | CPI developer docs | | Ingenico / Worldline | Color touchscreen (newer models) | Yes on newer models | REST API | No native crypto; middleware retrofit possible | Low — enterprise path only | Not publicly documented | | Tablet (any Android/iPad) | Large color — best for scanning | Yes — full control | BTCPay POS app, OpenNode app | Both fully verified | High — easiest QR UX, no MDB needed initially | BTCPay Server POS |

What is actually confirmed by primary docs:

  • Nayax officially documents Cortina DynamicQR, and its docs say the integrator returns QR data that is displayed on Nayax devices.
  • Nayax officially positions VPOS Touch as supporting QR-based payments.
  • BTCPay officially documents a public PoS app that runs on a web device for in-person checkout.

What is still not confirmed:

  • a public, production Lightning deployment on Nayax VPOS Touch
  • a public, production Lightning deployment on Cantaloupe Engage Pulse
  • any off-the-shelf Lightning plugin from Nayax or Cantaloupe

Nayax VPOS Touch — detailed notes

What it is: Nayax's flagship unattended payment device. Widely deployed globally. Accepts EMV, NFC (Apple/Google/Samsung Pay), QR codes (Alipay, WeChat Pay confirmed), and magnetic stripe.

Screen: 2.4-inch color touchscreen. Small but functional for QR scanning.

The Cortina API is Nayax's third-party gateway integration layer. It allows an external payment provider to act as the payment processor for the VPOS Touch. Flow:

  1. Machine sends payment request to Cortina endpoint
  2. Cortina routes to the configured gateway (normally a card processor)
  3. With modification: route to a crypto gateway (BitPay, OpenNode, GoCrypto) instead
  4. Gateway returns a QR string or payment URL
  5. VPOS Touch renders it

Confidence caveat: Nayax's public docs confirm Cortina works for "loyalty cards, closed-loop payment methods, and custom payment flows." They do not explicitly name Bitcoin or Lightning in any developer docs found. The path is technically plausible but requires direct Nayax developer engagement to confirm.

Spark API: A separate Nayax API for initiating sessions and handling card payment flows from a backend. Less relevant for Lightning but worth knowing exists for hybrid setups.

Recommended action: Contact Nayax developer support and ask specifically: "Can the Cortina API be configured to route to a third-party Bitcoin Lightning gateway like OpenNode or BTCPay Server? Has anyone done this before?"

  • Nayax developer hub: https://developerhub.nayax.com/
  • Cortina API reference: https://developerhub.nayax.com/reference/cortina-api-overview

Cantaloupe Engage Pulse — detailed notes

What it is: Cantaloupe's modern touchscreen card reader for vending and amusement. Replaced the E-Port G11 in Cantaloupe's lineup.

Screen: Edge-to-edge color touchscreen. Larger and higher-res than the VPOS Touch. Better QR scanning UX.

Crypto history: Cantaloupe announced a Bakkt partnership in 2021 allowing customers to spend bitcoin and supported loyalty points through the Bakkt app on Cantaloupe's unattended retail network. This was a custodial integration — customer pays through Bakkt, Bakkt settles through the Cantaloupe flow. Not a Lightning integration.

Lightning status: No confirmed native Lightning support found. The Bakkt path could theoretically be extended, but Bakkt does not offer Lightning payments.

Custom QR path: Cantaloupe's SDK allows custom payment flows. A custom QR invoice from BTCPay or OpenNode could theoretically display on the Engage Pulse screen via the SDK. Not confirmed in production.

Recommended action: Contact Cantaloupe and ask about custom payment gateway integration via their SDK. Ask whether the Engage Pulse can display dynamic QR codes from a third-party payment provider.

  • Cantaloupe store: https://store.cantaloupe.com/products/engage-pulse
  • Cantaloupe card readers: https://www.cantaloupe.com/products/point-of-sale/card-readers/

Payment gateway comparison

| Gateway | Lightning | On-chain | Self-custody | Fees | Best for | |---|---|---|---|---|---| | BTCPay Server | Yes | Yes | Yes — you control keys | 0% (self-hosted) | Sovereign operators, custom builds | | OpenNode | Yes | Yes | No — custodial | 1% | Fast setup, API-first, developer-friendly | | BitPay | Yes | Yes | No — custodial | 1% | Enterprise integrations, Nayax/Cantaloupe targeting | | GoCrypto | Yes | Yes | No — custodial | Varies | European market focus, retail POS | | LNbits | Yes (Lightning only) | No | Depends on funding source | 0% (self-hosted) | DIY/family builds, low-cost deployments |

Recommendation for first machine: BTCPay Server if you want sovereignty and control. OpenNode if you want the fastest path to a working API integration without self-hosting a Lightning node.

The practical MVP path (verified)

This is the path with the most confirmed working implementations:

Tablet (Android or iPad)
  ↓
BTCPay Server POS web app (self-hosted or BTCPay.net)
  ↓
Lightning invoice generated → QR displayed on tablet screen
  ↓
Customer scans with Phoenix / Wallet of Satoshi
  ↓
BTCPay webhook fires → payment confirmed
  ↓
Raspberry Pi receives signal → sends MDB command
  ↓
Vending machine vends

Integration path decision tree

Do you want commercial-grade hardware (Nayax/Cantaloupe)?
  YES → Contact Nayax/Cantaloupe dev support first to confirm Lightning gateway path
        If confirmed: use Cortina API (Nayax) or Cantaloupe SDK + OpenNode/BitPay
        If not confirmed: fall back to tablet overlay on existing machine
  NO → Use Raspberry Pi + tablet stack with BTCPay
       Lowest risk, most documented, full sovereignty

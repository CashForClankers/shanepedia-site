Micro-site factory

The micro-site factory is the production system behind operator site rescue and future product launches. It is not a website builder — it is an agent-assisted pipeline that turns operator information into live, fast, beautiful single-page sites.

How it works

Input

  • Operator photos (from Telegram, WhatsApp, or in-person)
  • Basic info: what they offer, pricing, location, contact
  • Language: Spanish primary, English translation by agent

Processing

  • Agent generates HTML from a template library
  • Agent writes bilingual copy from operator input
  • Agent selects and crops best photos
  • Agent generates WhatsApp deep link with pre-filled message
  • Agent validates mobile rendering and load time

Output

  • Single HTML file, self-contained or with minimal assets
  • Hosted on GitHub Pages (free, fast CDN)
  • Custom domain optional ($10-15/year)
  • WhatsApp Business quick-reply pack as companion deliverable

Template library

Build 4-5 base templates covering common operator types:

  1. Tour operator — hero photo, experience description, pricing table, seasonal info, WhatsApp CTA
  2. Accommodation — room gallery, amenities, location map, booking CTA
  3. Restaurant/cafe — menu highlights, atmosphere photos, hours, directions
  4. Experience provider — what you'll do, what's included, difficulty level, group size, CTA
  5. Multi-service — operator offering tours + stays + food as a package

Design standards

Every site from the factory follows Shane's design taste:

  • Loads in under 2 seconds
  • Mobile-first (most tourists browse on phone)
  • Clear hierarchy: what → why → how much → book now
  • No stock photos — real operator photos only
  • Bilingual without toggle complexity (Spanish sections + English sections)
  • WhatsApp as primary CTA, not a form

Agent automation depth

The factory should eventually run with minimal human input:

  1. Operator sends photos and info via WhatsApp or Telegram
  2. Agent drafts site and copy
  3. Shane reviews and approves (5 minutes)
  4. Agent deploys to GitHub Pages
  5. Agent sends operator the live link

Relationship to Shanepedia

The factory is a child project. Its templates, deployment scripts, and client list should be tracked as a project lane under Shanepedia. Operator research and learnings flow back into the wiki.

Business seed: August Booking Sprint

  • Seasonal offer for coastal operators before August booking windows, especially in Los Cobanos, El Tunco, and El Zonte where English-language web presence is still weak.
  • Deliverable is a bilingual one-page site plus WhatsApp booking funnel, built from operator photos and pricing in the existing micro-site factory pipeline.
  • Price as a fast-launch package, for example $350 setup plus $79/month for edits, hosting, and quick-reply maintenance during the season.
  • Agents handle copy drafts, photo selection, translation, mobile QA, and deployment, leaving Shane with a short approval pass.
  • Best first buyers are whale-season and experience operators who already sell over WhatsApp but miss foreign demand because they have no fast booking page.

Business seed: Operator Evidence Pack

  • Productized intake layer for the micro-site factory: agents turn raw WhatsApp photos, prices, FAQs, and voice notes into a clean bilingual operator asset packet.
  • Best early buyers are El Salvador operators like Los Cóbanos tour providers who already sell over chat but lack reusable, trustworthy marketing inputs.
  • Deliverables include approved copy blocks, captioned photo picks, a pricing/FAQ sheet, WhatsApp reply snippets, and a ready-to-deploy booking CTA.
  • Price as $250 setup plus $79/month for seasonal edits, new photos, and English/Spanish refreshes before booking pushes.
  • This fills a real wiki gap between relationship research and final launch pages: the reusable evidence layer that makes fast, tasteful sites possible.

Business seed: 48-Hour Booking Friction Brief

  • A paid intelligence brief built from the micro-site factory pipeline: agents audit an operator’s current WhatsApp booking flow, English visibility, and mobile trust signals in under 48 hours.
  • Best first buyers are Los Cóbanos and El Tunco operators identified in the 2026 tourism landscape as high-demand but digitally under-tooled.
  • Deliverable includes a 1-page friction scorecard, bilingual copy fixes, a recommended single-page layout, and ready-to-send WhatsApp reply scripts.
  • Price at $199 one-time with a $79/month refresh option before seasonal demand spikes (including whale season packaging).
  • Claude/Gemini/Codex can automate screenshot analysis, bilingual rewrite drafts, and first-pass page scaffolding, leaving only a short human approval pass.

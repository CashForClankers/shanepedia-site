Shane Feed

This is the "open first" surface. It should answer three questions quickly: what is interesting right now, what moved today, and what should Shane be asked to update next.

Open now

  • What's Cooking - the current state of the world: active builds, stuck items, recent wins, and the next thing to ship.
  • Recent Activity - what changed recently without reading the full log.
  • Public Offer Cards - public-safe ideas that can become posts, landing pages, client offers, or demos.
  • The Shane Test - the filter for whether something belongs in the system.
  • Anti-Roadmap — Things Shane Should Not Build - good ways to avoid wasting Shane time.

Obviously relevant right now

  • Gresham Vending Ops — Running a Machine in East Portland and Vending Machine Location Pitch — Finding and Winning Placements - get one food cart pod handshake before buying hardware.
  • OpenCluck — Chicken Coop IoT Monitor and Backyard Chickens — Oregon Keeper Notes - deploy the smallest chicken monitor before making it fancy.
  • Agent Leverage Stack — How Shane Actually Uses AI and Cron as Product — Push-Based AI Beats Pull-Based AI - make agents feel like useful daily infrastructure, not long chat transcripts.
  • YouTube randomness to Shanepedia spark - use public YouTube randomness as a spark, then write the durable part back to the wiki.

What crons should add

Every daily Shanepedia cron should leave one durable page behind. A Telegram note is useful, but the site should also grow by one small page each day:

  • a daily feed page under wiki/daily/
  • a link from this dashboard's archive
  • rebuilt local site output
  • rebuilt public artifact for GitHub Pages

Better daily prompt shape

The cron should not say "here is a random page" and stop. It should say:

  1. what page or idea surfaced
  2. why it is interesting now
  3. what changed today in the wiki or cron system
  4. one direct question: add to it, update it, productize it, or ignore it?

Kill boring feed items

If a card is generic, too long, or repeats yesterday, it should be demoted. The feed earns its place by being concrete: vending target, chicken sensor, Bitcoin merchant, public offer, travel operator, local family idea, or agent/tooling improvement.

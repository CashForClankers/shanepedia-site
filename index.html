Shanepedia Overview

Shanepedia is the parent founder/operator wiki for Shane's life, businesses, projects, relationships, trips, history, and ongoing research. This repository is the correct root for that system. ElSalKB is just one child lane inside it.

Recent work

  • 2026-04-18: Local Bitcoin commerce lane — new parent-level work on building a circular bitcoin economy around Gresham / Portland / Happy Valley by combining merchant discovery with owned spend surfaces. Start with bitcoin-circular-economy-portland.
  • 2026-04-18: Bitcoin-accepting vending machine concept — a hot sauce vending machine at food cart pods as the first owned Lightning + card spend surface and a live proof-of-demand node. See hot-sauce-vending-machine.
  • 2026-04-18: Terminal implementation path — concrete hardware/software notes for getting a vending machine to accept Lightning and cards, then dispense reliably. See vending-machine-terminal-tech.

Active business idea lanes

The most promising ideas in the current corpus are not one big startup — they are several linked lanes that compound:

  • Operator site rescue — the first launchable business. Fast website + WhatsApp funnel builds for tourism operators with no English web presence. $150-500 per client, near-zero cost. See operator-site-rescue.
  • WhatsApp booking funnels — structured booking flows replacing chaotic DMs. The key channel for every operator. See whatsapp-booking-funnels.
  • Los Cobanos marine products — whale watching (Oct-Feb), reef snorkeling, marine fauna tours. 43 authorized guides, booming demand, weak online packaging. See los-cobanos-marine-products.
  • Coffee route agritourism — Ruta de las Flores finca tours, highland arcs, birding. Strong heritage stories, no one packages the multi-day arc. See coffee-route-agritourism-products.
  • Micro-site factory — agent-assisted production pipeline: operator photos in, live sites out in 48 hours. See micro-site-factory.
  • Agentic business studio — the wiki itself as an agent-readable system that turns people, places, businesses, and photos into executable projects. See agentic-business-studio.
  • Bitcoin travel onboarding — dual-audience offers bridging crypto-native visitors and local operators. See bitcoin-travel-onboarding.
  • Bitcoin commerce map — the business graph behind Bitcoin tourism products and verification opportunities. See bitcoin-commerce-map.
  • Local bitcoin commerce lab — the Portland / Gresham / Happy Valley extension: multi-map merchant discovery plus owned Bitcoin vending experiments. See bitcoin-circular-economy-portland, hot-sauce-vending-machine, and vending-machine-terminal-tech.
  • Niche experience products — poorly packaged high-value experiences that could become bookable offers. See niche-experience-products.
  • El Salvador market landscape — tourism up 30%+ since 2021, 300% growth in Bitcoin-adjacent sectors, digital nomad infrastructure expanding fast. See el-salvador-tourism-landscape-2026.

Parent-child model

  • Parent system: Shanepedia stores the durable model of Shane's voice, preferences, projects, contacts, and business opportunities.
  • Child lanes: ElSalKB, local-operator site work, trip programs, and future ventures are project lanes that link upward into Shanepedia rather than absorb it.
  • Operator rule: when a source is specific to El Salvador or a single operator, capture the local detail and also state what it teaches the broader founder system.

Next steps

  1. Keep expanding Shanepedia at the founder level, not just at the current El Salvador lane level.
  2. Add explicit project pages for current and future businesses, sites, research lanes, and travel programs.
  3. Start a history layer so past chapters and recurring patterns do not get flattened into the present.
  4. Keep the agent runtime and research flywheel documented inside the wiki so other agents can use the parent system without guessing commands or roots.
  5. Run recurring research, linking, and lint cycles so the wiki becomes an active operating system rather than a static archive.
